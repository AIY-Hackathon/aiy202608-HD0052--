## 1. 冲刺总览

### 1.1 目标

三天内完成一个**可演示的基因分析助手 MVP**，包含以下核心功能：

1. ✅ 基因报告（VCF）上传 → 自动分析 → 风险报告
2. ✅ 交互式健康模拟（基因×环境因素→健康轨迹）
3. ✅ 个性化生活方式建议
4. ✅ PDF/HTML 报告导出
5. ✅ FDA 合规免责声明 + AI 内容透明标注

### 1.2 技术栈决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 前端框架 | **Streamlit**（非 React） | 纯 Python，30 分钟搭建仪表板 |
| AI 演示 | **Gradio**（独立页面） | 一行代码构建 AI 判读界面 |
| 可视化 | **D3.js + Recharts**（嵌入 Streamlit） | 已移除 Three.js 3D 方案 |
| 搜索 | **PostgreSQL 全文搜索** | 已降级 Elasticsearch 至 Phase 2 |
| 数据 | **本地预下载数据库** | ClinVar VCF + 1000 Genomes + GIAB + RefSeq |

### 1.3 本地数据资源（已下载中 🔄）

| 数据集 | 本地路径 | 大小 | 用途 |
|--------|----------|------|------|
| ClinVar VCF | `data/clinvar/clinvar_grch38.vcf.gz` | ~200 MB | 变异临床意义注释 |
| 1000 Genomes | `data/1000genomes/` | ~50 MB | 人群频率参考 |
| GIAB | `data/giab/` | ~100 MB | 基准验证 |
| RefSeq | `data/refseq/` | ~500 MB | 参考序列 |

## 2. Day 1：核心管道搭建（8 小时）

> **目标**：用户可上传 VCF 文件 → 系统解析变异 → 查询 ClinVar 数据库 → 生成基础分析报告

### 上午（4h）：环境搭建 + 数据层

- [ ] **1.1 开发环境初始化**（30 min）
  - 创建 Python 虚拟环境
  - 安装核心依赖：`streamlit`, `gradio`, `fastapi`, `pandas`, `biopython`, `pyvcf`, `psycopg2`, `redis`, `sqlalchemy`
  - Docker 启动 PostgreSQL + Redis
  - _交付物：可运行的 `python -c "import streamlit; import pandas; import Bio"`_

- [ ] **1.2 数据库模式创建**（45 min）
  - 执行设计文档 §5 的 SQL 建表语句（users、genetic_reports、genetic_variants、simulation_scenarios、recommendations）
  - 配置 Alembic 迁移
  - _交付物：PostgreSQL 中五张表创建完成_

- [ ] **1.3 本地数据文件加载**（45 min）
  - 验证 ClinVar VCF 文件完整性（md5 校验）
  - 创建 ClinVar VCF 索引（tabix）
  - 将 ClinVar 关键字段导入 PostgreSQL（可选，加速查询）
  - _交付物：`data/clinvar/clinvar_grch38.vcf.gz.tbi` 索引文件_

- [ ] **1.4 VCF 解析器实现**（1.5 h）
  - 实现 `utils/vcf_parser.py`：支持 `pyvcf` 和 `pandas` 双方案
  - 提取关键字段：CHROM、POS、ID、REF、ALT、QUAL、FILTER、INFO
  - 解析 INFO 字段中的基因名（GENEINFO）和临床意义（CLNSIG）
  - _关联需求：R1.1, R1.2_

- [ ] **1.5 ClinVar 查询客户端**（1 h）
  - 实现 `utils/clinvar_client.py`
  - 优先查询本地 VCF 文件（tabix 按位置查询）
  - 未命中时回退到 NCBI E-utilities API
  - 缓存查询结果到 Redis
  - _关联需求：R7.1, R7.2_

- [ ] **1.6 检查点 1**（30 min）
  - 测试：真实 VCF 文件 → 解析出变异列表 → ClinVar 匹配成功
  - 记录遇到的任何格式兼容性问题

- [ ] **1.7 FastAPI 后端搭建**（1.5 h）

  - _关联需求：R6.1, R6.3, R6.4_

- [ ] **1.9 端到端集成测试**（45 min）

  - _关联需求：全部 P0 需求_

- [ ] **1.10 Day 1 收尾**（30 min）

  - 记录待解决问题清单
  - 更新明日计划

## 3. Day 2：模拟引擎与建议系统（8 小时）

> **目标**：交互式健康模拟器 + 个性化建议引擎 + 报告导出

### 上午（4h）：健康模拟引擎

- [ ] **2.1 PRS 计算器实现**（1 h）
  - 实现 `utils/prs_calculator.py`
  - 基于 ClinVar odds_ratio 和人群频率计算加权风险评分
  - 生成置信区间
  - _关联需求：R1.4, R11.1_

- [ ] **2.2 GxE 模型实现**（1.5 h）
  - 实现基因-环境交互数学模型
  - 环境因素：饮食（高/中/低风险）、运动（频率/强度）、吸烟、饮酒、BMI
  - 每个因素设定生物学合理范围
  - 计算综合健康风险得分
  - _关联需求：R3.1, R3.2, R3.4, R3.7_

- [ ] **2.3 模拟 API 端点**（45 min）
  - 创建 `/api/simulate` 端点（返回健康轨迹数据）
  - 返回格式：`{ timeline, risk_scores, confidence_intervals }`
  - _关联需求：R3.5, R3.6_

- [ ] **2.4 Streamlit 模拟器界面**（45 min）
  - 创建 `pages/3_Simulator.py`
  - 环境因素交互式滑块（Streamlit `st.slider`）
  - 健康轨迹折线图（D3.js 通过 Streamlit 组件嵌入）
  - 多场景对比保存功能
  - _关联需求：R6.2, R6.3_

---

### 下午（4h）：建议引擎 + 报告导出

- [ ] **2.5 建议引擎实现**（1 h）
  - 实现基于 PRS 风险档案的建议生成逻辑

  - 优先级排序算法（影响力 × 可行性）
  - _关联需求：R4.1, R4.2, R4.4_

- [ ] **2.6 建议 API 端点**（30 min）
  - 创建 `/api/recommendations` 端点
  - 返回结构化建议列表 + 证据链接
  - _关联需求：R4.2, R4.3_

- [ ] **2.7 Streamlit 建议界面**（45 min）
  - 创建 `pages/4_Recommendations.py`
  - 按优先级排列的建议卡片
  - 每条建议附带证据来源和难度标签
  - 进度跟踪复选框
  - _关联需求：R4.5, R4.7_

  - 包含：变异摘要、风险评估、健康模拟结果、建议清单
  - _关联需求：R8.1, R8.2, R8.4, R8.6_
